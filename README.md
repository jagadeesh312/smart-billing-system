I am currently building a Smart Billing Web Application using HTML, CSS, and JavaScript with Firebase integration. The project includes a secure login system with role-based access for Admin and Employee users. After login, the dashboard displays the user name, a professional navigation bar, and main sections such as task management, AI voice input, and a monthly calendar. The system stores and retrieves data using Firebase Authentication and Realtime Database. I am focusing on creating a modern glass-style user interface with clean layout design and smooth functionality. My goal is to build a fully working, professional web application with complete front-end design and backend logic integration.
