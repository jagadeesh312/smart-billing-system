# 🧾 Smart Billing AI System

An intelligent billing and retail management web application designed to simplify product management, invoice generation, GST calculation, and sales tracking. The project aims to make everyday billing faster and easier with AI-assisted product selection.

## ✨ Features

- 📦 Product and inventory management
- 🧾 Automated bill generation
- 🧮 GST calculation
- 🖨️ Printable customer invoices
- 📱 QR-based UPI payment support
- 🎙️ AI-assisted voice and text product selection
- 📊 Sales history and reporting
- 👥 Admin and employee workflows
- 🌐 Responsive user interface

## 🛠️ Technology Stack

- HTML5
- CSS3
- JavaScript
- Firebase Authentication and database services
- Google Gemini API for AI features
- QR code integration for payment workflows

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Configure Firebase for the services your application uses.
4. Configure your AI API key securely if AI features are enabled.
5. Run the application using a local development server.

## 🔐 Security

- Never commit API keys, passwords, or private credentials.
- Configure Firebase security rules before deployment.
- Validate billing and payment data on a trusted backend where required.
- Verify payment status before marking an invoice as paid.
